# Mint on the Avenue V2 Design Specification

## Vision

Mint on the Avenue V2 is a futuristic eco-luxury salon flagship website designed as if it exists in 2028. It should feel like a calm, naturally lit beauty sanctuary, a high-fashion editorial, and a premium wellness-tech experience.

The site must not feel like a generic salon website. It should feel white-dominant, airy, botanical, architectural, cinematic, and conversion-focused.

Core feeling:

> A breath of fresh air for modern hair.

## Color System

White and ivory dominate. Green should feel sage, eucalyptus, mineral, botanical, and refined.

Primary palette:

- Atmospheric white: `#fbfbf6`
- Warm ivory: `#f1ecdf`
- Soft botanical mist: `#e5e8d6`
- Pale sage: `#ccd6c0`
- Eucalyptus: `#8da48d`
- Mineral sage: `#647962`
- Olive shadow: `#50563d`
- Deep botanical: `#0b2e27`
- Botanical ink: `#1c1a0f`
- Brushed titanium: `#c9c8bd`
- Warm taupe accent: `#c4b8a0`

Usage:

- 65% atmospheric white and ivory
- 20% pale sage and eucalyptus
- 10% mineral/titanium structure
- 5% deep botanical contrast

Do not use `#5bbbc9` as a dominant color. Do not make the site feel blue.

## Typography

Typography should feel editorial, refined, sculptural, and calm.

Recommended direction:

- Large cinematic H1s
- Clean modern sans-serif body copy
- High contrast hierarchy
- Spacious line-height
- Strong whitespace
- Uppercase micro-labels with generous tracking
- Text reveals that feel soft and premium

Rules:

- One H1 per page.
- Do not use aggressive sci-fi fonts.
- Do not let text overlap images.
- Body text must remain highly readable on mobile.

## Motion System

Motion must feel like breath, not spectacle.

Default easing:

- Luxury ease: `cubic-bezier(0.22, 1, 0.36, 1)`
- Gentle in-out: `cubic-bezier(0.65, 0, 0.35, 1)`

Timing:

- Header transition: 300ms
- Button hover: 180ms
- Card hover: 240ms
- Text reveal: 700ms
- Image reveal: 900ms
- Section reveal: 900-1200ms
- Page transition: 650ms
- Modal open: 420ms
- Modal close: 260ms
- Booking step transition: 450ms
- Accordion open: 320ms

Motion rules:

- Use slow fades, soft blur removal, gentle upward drift, and subtle image scale.
- Parallax must be low-amplitude and atmospheric.
- Buttons compress slightly on click.
- Cards lift subtly on hover.
- Disable heavy motion for `prefers-reduced-motion`.

## Interaction Rules

Buttons:

- Hover: soft glow, arrow moves 4px right.
- Click: scale to 0.985 briefly.
- Disabled: low contrast but still readable.

Cards:

- Hover: lift 4px, image scale 1.03, border warms.
- Click: open details or route.

Accordions:

- Click opens with smooth height animation.
- Only one section open at a time on mobile if space feels tight.

Modals:

- Open with blur/fade.
- Trap focus.
- Escape closes.
- Outside click closes unless form data would be lost.

Forms:

- Focus: sage glow.
- Invalid submit: inline errors.
- Successful submit: calm confirmation.
- Preserve data after failure.

## Loading and Error States

Loading:

- Use pale sage/ivory skeletons.
- Avoid generic spinners where possible.

Empty:

- Lookbook: “No looks found for this filter yet.”
- Search: “Try ‘color’, ‘new guest’, or ‘parking’.”
- Artist filter: “No exact match yet. Let us help pair you.”

Failure:

- Booking: “Something did not send. Your details are still here. Please try again or call us.”
- Contact: “We could not send this message yet. Please try again or call 407.645.2264.”

## SEO

Every major page needs:

- Unique title
- Unique meta description
- One H1
- Clean URL
- Open Graph tags
- Descriptive alt text

Local SEO:

- Use consistent name, address, phone.
- Add HairSalon or LocalBusiness schema.
- Add opening hours when confirmed.
- Add natural local terms such as “Aveda salon Winter Park” and “hair color Winter Park.”

## Asset Rules

Use uploaded assets as source of truth.

Suggested structure:

- `src/assets/logo-mint-black.png`
- `src/assets/logo-mint-white.png`
- `src/assets/campaign-hero-breath-of-nature.png`
- `src/assets/campaign-rooted-in-nature.png`
- `src/assets/texture-botanical-dark.png`
- `src/assets/texture-sage-mineral.png`
- `src/assets/lookbook-placeholder-01.png`

Rules:

- Never stretch images.
- Use intentional focal positions.
- Optimize image size.
- Decorative textures use empty alt text.
- Informational images use descriptive alt text.

## Mobile Rules

Mobile is not just responsive. It must feel native.

Rules:

- Full-screen menu.
- Sticky Book CTA after hero.
- One-column editorial layouts.
- Large tap targets, minimum 44px.
- Reduced parallax.
- Booking one step per screen.
- Lookbook supports swipe-like navigation.
- Text never sits over busy faces or hair details.

The site is done only when:

- Every route opens.
- Every CTA works.
- Booking can be reached from every major page.
- Services are readable and organized.
- New guests have a clear guided path.
- Artist matching exists.
- Lookbook modal works with previous, next, close, and booking.
- Contact details are consistent everywhere.
- Mobile nav is elegant and usable.
- No text overlaps.
- Reduced motion works.
- Palette reads ivory, sage, eucalyptus, mineral, botanical, and warm.
- Site does not feel cyan, blue, neon, or generic.
- The experience feels premium while practical information remains easy to find.
